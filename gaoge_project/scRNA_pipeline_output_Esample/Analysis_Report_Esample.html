注释方法

1. 分析方案与注释体系

流程主线：① 单样本质控与聚类（Cell Ranger + Seurat QC + 降维聚类）；② 单样本 scVI 注释（GSM4794634 参考，3-fold 集成 KNN 标签迁移 + 多数投票）；③ TGWT_merge（12 样本唯一合并对象）五视图同步分析（Merge / Tg / WT / E12 / E16 均为同一注释结果的细胞子集视图）；④ 5 个分化谱系 Focus 群体高亮 UMAP。

注释层级：L0 predicted_Predicted_Celltype_mapped（7 类群一阶归并）；L1 predicted_Predicted_Celltype_cluster（Seurat cluster 众数标签）；L2 predicted_Predicted_Celltype_L2（区内再聚类亚型）；最终主注释 predicted_Predicted_Celltype_resolved（融合 L1 与 L2，11 类群）。单细胞原始标签 predicted_Predicted_Celltype（15 类）完整保留在 metadata 中。
