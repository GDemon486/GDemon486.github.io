1. 数据概览与上机质控

本组学与 sc_10x 为同一次 Chromium GEM 分库的双平台测序（Nanopore 全长 cDNA），因此 10X Nanobarcode 在两平台一一对应（barcode 交叠 100%，见第 7 节）。上游 01 basecalling / 02 QC / 03 wf-single-cell 由测序公司完成，本报告记录其交付结果、细胞重捞回修正与本地 05/06/07/09 下游分析。

细胞重捞回（2026-09-20 完成）：公司交付的细胞调用用 quantile 方法算出阈值 448 reads，把 13,401 个 10X 验证细胞（reads 22~447，中位 ~310，主要是低 RNA 的 Paneth Cells Progenitors）系统性丢弃。修正：wf-single-cell 2.2.0 原参数重跑（细胞调用改 abundance ≥50 reads）+ 10X barcode 白名单对齐（BLAZE/ScNapBar matched-short-read 策略）。最终 55,983/55,985（99.996%）细胞与 10X 完全对齐，PCP 从 301/314/136/183 恢复到 3,397/6,465/2,541/3,704（与 10X 一致，仅 KO 因 2 个细胞 reads<50 未恢复）。
重要提示：每种基因型仅 1 个生物学样本（n=1/组，两平台一致）。06 DTU 的 p 值来自伪重复（每样本细胞拆 3 份），偏乐观、仅作探索性排序；正式统计结论依赖补送生物学重复（见 06 说明文件）。

reads / full-length 数取自 wf-single-cell 交付的 config_stats.json；检测细胞数 = 白名单对齐后的最终细胞数（与 10X filtered 矩阵一致）。

6. 可变多聚腺苷酸化 APA（07，描述性）

基于 GFF 3' 端簇调用 PAS（poly(A) 位点），构建 consensus PAU 矩阵，计算每对比的 ΔPAU 与基因级 3'UTR 延长指数（distal change）。严格统计版（APALORD）需 IsoQuant 前置文件，交付数据暂缺，故为描述性结果。

直方图过滤说明：原始直方图左右两侧均出现高峰，根因是 63.7% 的基因仅有 1 个 PAS，其 PAU 值非 0 即 1——基因在某样本中未检出（PAU=0）vs 检出（PAU=1）产生 |ΔPAU|=1 的 dropout 噪声，制造左右对称的假信号。已修复：直方图仅保留两侧都检出（0 < PAU < 1）的基因，过滤掉 ~9,240 个 dropout 基因，仅保留 ~1,240 个真实 APA 变化基因。

7. 与 10X 单细胞级整合（09，同 GEM 配对）

7.1 Barcode 交叠矩阵（配对验证）

Nanopore 各样本细胞 barcode 与 10X 四库的交叠百分比：对角线 = 配对样本（100%），非对角 ~0.4% 为随机本底。细胞重捞回后对角线达到满值。

7.2 配对概览与双平台一致性

shared_cells = barcode 在双平台同时检出且计入 10X filtered 矩阵的细胞；nCount_spearman = 共享细胞双平台 UMI 数相关性（log1p）；pb_gene_spearman = 配对 pseudobulk 基因表达 Spearman。细胞重捞回后 nano 细胞数与 10X 完全一致，单细胞 UMI 相关性从 ~0.89 提升至 ~0.987。

7.3 细胞类型组成比较（Nanopore vs 10X）

PCP 恢复验证：细胞重捞回前 Paneth Cells Progenitors 在 Nanopore 端仅检出 10X 的 5~12%（301/314/136/183）；重捞回后 WT 3,397 / KO 6,465 / A1-Het 2,541 / A1-Rescue 3,704，与 10X 逐一精确对齐（KO 差 2 个 = reads<50 的未恢复细胞）。所有其余细胞类型（ISC、TA、Enterocytes、Paneth 等）两平台计数完全一致。

7.4 Nanopore 细胞类型标签转移 UMAP

10X 注释的细胞类型标签通过 barcode（同 GEM 配对，匹配率 ~100%）直接转移到 Nanopore 细胞，在 Nanopore 自建 UMAP 上可视化验证转移效果。

7.5 探索性 logFC 一致性（基因层，n=1/组）

双平台各自 pseudobulk 计算基因 log2FC，比较方向一致性（Spearman rho）。细胞重捞回后 rho 0.43~0.50，双平台基因层方向一致性良好（n=1，转录本层差异以 Nanopore 全长读数为准）。橙色点为 Sirt6 / Hnrnpa1。
