当前映射：`TXdB7j → KO`、`TXdH8k → A1-Rescue`、`TXdC7j → A1-Het`、`TXdE5k → WT`。依据是 barcode 重叠实证（99.6%~100%）与 2026-09-21 的 KO/A1-Het 对调勘误。**脚本侧仍未置为已确认**；拿到公司样本表后应先核对，再解读任何按基因型分组的结论。

### 2.2 生物学重复 n = 1 / 基因型

每个基因型只有 1 个样本（两平台一致）。因此：

- 所有差异都是**样本间**差异，无法与生物学个体差异分离；
- 06 DTU 的 p 值来自**伪重复**（每样本细胞随机拆 3 份），偏乐观；
- 09 / 10 的相关系数与效应量同样只到描述性层面。

正式结论依赖补送生物学重复。

## 4. 第 5–8 节的解读限制

### 4.1 DTU（06）：satuRn 有结果 ≠ 有 63% 的真差异

- 设计是每样本细胞随机拆 3 份的伪重复，`df ≈ 14`。**所有检验量的方差被系统性低估**，因此 padj<0.05 达到 63%~64.5%（17,676~18,101 / 28,067），这个比例不能当作"真实差异转录本占比"。
- 最小 padj 的记录是 `Rpl4` 的两个转录本，`estimates = ±12.00`、`t = ±132.9`——同一基因两个近似重复 isoform 的对倒，属于注释/读段分配层面的二值切换，不是定量意义上的使用差异。
- `usage_delta_*.csv` 记录的是 0/1 presence 切换（某转录本在两组 pseudobulk 中有无），不是 PSI；`|Δusage| ≥ 0.05` 会覆盖约 2.5 万条，同样只能用于探索性排序。
- 实际可用的做法：以 `estimates` 的**方向和幅度** + `usage_delta` + 表达量三者交叉筛选，再人工核对转录本结构。

### 4.2 APA（07）：65% 的基因只有一个 PAS

- consensus 中 32,156 个基因里约 65% 只有 1 个 PAS，其 PAU 非 0 即 1。基因在某样本未检出（PAU=0）vs 检出（PAU=1）会产生 |ΔPAU| = 1 的 dropout 噪声，制造左右对称的假信号。
- 因此直方图只保留**两侧都检出**（0 < PAU < 1）的基因：每对比剔除约 10,036~10,053 个基因，保留 1,256~1,273 个。图中显示的是过滤后的分布。
- 严格统计版（APALORD）需要 IsoQuant 前置文件，交付数据暂缺，本节全部为描述性结果。

### 4.3 与 10X 整合（09）：三个容易误读的点

1. **注释覆盖率 100%**：分母是 QC 后的 nano 细胞；对全部 nano 细胞仍是 42.6%~65.7%。
2. **组成比较是 sanity check，不是独立验证**：10X 与 Nanopore 两侧用的是同一批注释细胞、同一套标签（barcode 转移），所以点全部落在对角线上是构造上的必然。上一版（2026-09-21）曾用"10X 全库 vs Nanopore 共享细胞"做过独立比对，本版不再提供该证据。
3. **双平台 UMAP 不是整合结果**：图注自述 `coordinates shared by design`，两个面板用完全相同的 UMAP 坐标，只换着色，因此不能作为批次校正/整合效果的证据。
4. 组成本身存在基因型间差异：KO 的 Cybrd1+ ent 占 15.6%、Imm ent 占 3.1%，而 WT 分别为 0.9% 与 25.3%。这是真实差异与注释覆盖差异的叠加，正式分析需分层核对。

### 4.4 全局可变剪接（10）：描述性效应量，不能当"剪接重编程"结论

**定义回顾**：IF = 转录本 UMI / 同基因全部转录本 UMI；ΔIF = IF(扰动) − IF(WT)；转录本层 `RI = 1 − ΔIF_Res/ΔIF_Pert`，基因层 `RI = 1 − ‖ΔIF_Res‖/‖ΔIF_Pert‖`（模长比）。

| 现象 | 数字 | 含义 |
|---|---|---|
| 基因层 over-rescued 恒为 0 | RI ≤ 1（模长比上限） | **数学必然**，不是"没有过回复基因"的生物学发现；转录本层用标量比才会出现 1,004 / 954 个 |
| 三组对比的 ECDF 几乎重合 | 中位 max\|ΔIF\| 0.136 / 0.134 / 0.138 | 该指标对基因型没有区分度，不能据此说"KO 造成了全局剪接位移" |
| 近半数"变化"在检出边界 | 受影响转录本中 **46.6%** 有一端 IF<0.05 | 是检出/未检出，而非比例移动，与 4.2 的 dropout 同源 |
| 效应量随表达量升高而下降 | 最低表达五分位 47.9% 被判"受影响"，最高五分位 25.9% | 典型噪声特征 |
| 三个 ΔIF 共用 WT 作参照 | corr(ΔIF_KO, ΔIF_HET)=0.516，corr(ΔIF_KO, ΔIF_RES)=0.494（独立噪声理论值≈0.33） | 天然正相关；三个不同基因型都"离 WT 很远"更像参照侧问题 |
| 杂合子偏离更大 | 64.6% 的 Het 受影响转录本 \|ΔIF\| > \|ΔIF_KO\| | 与"杂合更轻"的预期相反，指向样本/文库层面的系统差异 |
| 排序第一梯队 | top100 中单位点离群：KO 36、WT 15、Het 0、Res 0；前 6 个基因 Rpl11 / Rpl12 / Prdx1 / Rpl4 / Wdr26 / Rps15a | 多为核糖体蛋白基因的 0↔1 二值翻转（注释近似重复），人工核查前不应作为剪接结论 |
| 阈值敏感 | \|ΔIF\| 阈值 0.05→0.30 时受影响基因数大幅变化，但 rescued 比例稳定在 25%~30% | "回复比例"较稳，"哪些基因变了"很不稳 |
| 基因层 RI 分布 | 受影响基因 RI 中位 0.093、75 分位 0.504 | 多数基因几乎没回复，约 1/4 有明显回复 |

**靶基因**：`Pkm` 是少数渐变型证据（WT 0.98 → KO 0.45 → Rescue 0.89，RI 0.83/0.90，判 rescued），可信度相对高；`Sirt6` 为 partial（RI 0.31/0.37）；`App`、`Bin1` 判 farther than KO；**`Hnrnpa1` 的 max|ΔIF| 仅 0.096/0.081，未过 0.10 阈值**，本节对其没有信息量。

**建议**：按 cell type 分层重算，剔除一端 IF<0.05 的边界翻转后再排序，并补生物学重复。
